# 머신러닝 요구사항

기존 따릉이 데이터 분석을 바탕으로 일별 총 대여건수 예측 문제를 진행한다.
1~7번은 필수, 8번은 선택이다. 1~6번은 구현·실행을 완료했으며 7~8번은 후속 작업이다.

| 번호 | 요구사항 | 완료 기준 |
|---|---|---|
| 1 | 머신러닝 문제 정의 | 예측 대상, 입력 정보, 예측 시점과 활용 목적 설명 |
| 2 | 전처리·피처 구성 및 누수 점검 | 전처리·파생 변수 생성, 입력의 가용 시점과 데이터 누수 검증 |
| 3 | 데이터 분할 및 기준선 설정 | 학습·검증·테스트 구분과 근거, 단순 기준선 설정 |
| 4 | 모델 학습 및 성능 비교 | 서로 다른 모델 2개 이상을 동일 조건에서 학습하고 여러 지표로 비교 |
| 5 | 교차검증 및 하이퍼파라미터 조정 | 데이터 특성에 맞는 교차검증, 주요 설정 조정과 선택 근거 기록 |
| 6 | 최종 평가 및 결과 해석 | 최종 테스트 평가, 오류·집단별 성능 분석, 시각화와 기존 분석 연결 |
| 7 | 모델 활용 방안 및 한계 | 실제 모델 입력·출력 예시, 적용 범위·한계·개선 사항 설명 |
| 8 | 추가 실험 및 모델 개선 (선택) | 비교 가능한 조건의 확장 실험과 성능·해석 변화 분석 |

각 요구사항은 코드, 실행 결과, 해석을 포함한 노트북으로 확인할 수 있게 작성한다.
데이터 준비 상태는 [데이터 복구 기록](DATA.md)을 참고한다.
