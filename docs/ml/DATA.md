# 5회차 데이터 복구 기록

2026-10-20에 서울 열린데이터광장 공식 내려받기 폼으로 다음 파일을 복구했다.

출처: [서울시 공공자전거 따릉이 이용현황, OA-14994](https://data.seoul.go.kr/dataList/OA-14994/F/1/datasetView.do)

| 파일 | 행 수 | 인코딩 |
|---|---:|---|
| 서울특별시 공공자전거 일별 대여건수_25.1-6.csv | 181 | CP949 |
| 서울특별시 공공자전거 일별 대여건수_25.7-12.csv | 184 | CP949 |
| 서울특별시 공공자전거 일별 대여건수_26.1-6.csv | 181 | CP949 |

제공기관·저작권자: 서울특별시. 이용 조건: 공공누리 1유형(출처표시).
공식 페이지 갱신주기는 반기다. 공개 배포 시점과 일별 관측 시점을 혼동하지 않는다.

실제 파일 검사 결과:
- 2025-01-01~2026-06-30, 546일.
- 날짜 중복 0건, 누락 날짜 0건.
- 대여건수는 모두 음이 아닌 정수로 파싱 가능.
- 원본 헤더: `대여일자`, `대여건수`.

복구 명령: `python scripts/download_ml_data.py`.
저장 위치는 `data/raw/`이며 `.gitignore`에 의해 GitHub에서 제외된다.
로컬 `ml_download_manifest.json`에 파일별 SHA-256, 인코딩, 행 수, 확인 시점을 기록한다.
기존 파일이 있으면 덮어쓰지 않고 검증한다. 재실행 시 manifest의 확인 시점은 갱신된다.

ASOS CSV는 아직 복구하지 않았다. 필수 실험은 달력·과거 대여건수로 진행하고,
기존 4회차 전체 노트북 재실행 또는 기상 확장에는 ASOS를 추가로 확보해야 한다.
이 검사는 요구사항 2번의 전체 피처 구현·검증 완료를 의미하지 않는다.
