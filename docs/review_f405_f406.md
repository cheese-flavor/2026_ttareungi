## 검토할 파일

1. `notebooks/analysis.ipynb`: F404 다음 F405·F406 섹션.
2. `outputs/f406/holdout_metrics.csv`: 고정 평가 지표.

4. `outputs/f406/subgroup_metrics.csv`: 월·강수별 오차.

## F405 요약

- 546일의 기상 상관, 강수 그룹, 동일 기간 연도 비교를 재계산했다.
- 강수일 평균은 약 27.52% 낮지만 인과·통계적 유의성을 주장하지 않는다.
- 2026년 1~6월 일평균은 전년 동일 기간 대비 약 1.43% 증가하나 월별 방향은 다르다.
- `is_rain`은 결측 여부 자체를 보존하지 않는다는 생성식상의 한계를 명시했다.
- 전일 시점 수요 예측의 목표·입력·시간 분할·기준선·평가·추가 정보를 설계했다.

## F406 요약

추가 외부 자료 없이 날짜에서 요일과 연중 주기를 파생해 분석 방법을 확장했다.
2025년 학습, 2026년 상반기 181일 평가에서 MAE는 날씨 모델 16,212건/일 → 날씨+달력 모델 12,383건/일로 약 23.62% 감소했다.
2025년 내부 검증의 한 구간은 오히려 악화했고 강수일 오차도 여전히 크다.
관측 날씨를 이용한 사후 비교로, 실제 전일 예보 서비스의 성능을 의미하지 않는다.
