## 2. 기상청 ASOS 108(서울) 일자료

| 항목 | 내용 |
|---|---|
| 파일 | `data/raw/asos_108_daily_20250101_20261014.csv` |
| 출처 | 기상자료개방포털(data.kma.go.kr) — 데이터 > 기상관측 > 지상 > 종관기상관측(ASOS) 일자료 조회서비스 |
| 수집 방법 | 웹사이트에서 직접 다운로드 (CSV) |
| 수집 시점 | 2026-10-15 |
| 데이터 범위 | 2025-01-01 ~ 2026-10-14, 지점번호 108 |
| 지점 정보 | `stnId=108` → `stnNm="서울"` (원본 데이터 2번째 컬럼에서 직접 확인됨). 서울 종로구에 위치한 종관기상관측(ASOS) 지점 |
| 분석 단위 | 1행 = 1일(서울 관측소) |
| 주요 변수(일부) | `tm`(날짜), `avgTa`/`minTa`/`maxTa`(평균/최저/최고기온), `sumRn`(일강수량), `avgWs`(평균풍속), `avgRhm`(평균습도) 등 60여 개 |
| 이용 조건 | 기상청 공공데이터로 통상 공공누리(KOGL) 출처표시 조건 적용. 정확한 라이선스 유형은 포털 이용약관에서 재확인 권장 |
| 원본 인코딩 | UTF-8 |
| 비고 | 분석 기간은 따릉이 데이터 범위(~2026-06-30)에 맞춰 트림 필요 |

- 병합 키: 따릉이 `대여일자` ↔ ASOS `tm`
- 병합 방식: inner join (양쪽 다 존재하는 날짜만) — 날짜 범위 불일치는 섹션 2 "비고" 참조
- 병합 후 저장 위치: `data/processed/merged_daily.csv` (UTF-8)
